# TeachAssist v1.5

TeachAssist v1.5 focuses on reliability, clearer feedback, and a more usable interface. The existing student-management and attendance commands remain available.

## Improvements and bug fixes

- Prevent an open window from overwriting student data changed by another window or a text editor. Restarting loads the latest data.
- Reject malformed data files and show clearer feedback when student data cannot be loaded.
- Keep attendance information visible when names or group labels are long and the window is narrow.
- Make Student ID badges easier to distinguish from group labels.
- Reopening Help through the menu or F1 preserves the active attendance view; running the `help` command closes that view.
- Avoid recording undo steps for commands that change nothing.
- Improve command logging, defensive checks, and automated test coverage.

## Documentation

The User Guide and Developer Guide have been updated to clarify command behaviour, attendance, data-file recovery, and error messages.

## Getting started

Download the JAR attached to this release and follow the [User Guide](https://ay2627s1-cs2103t-f12-1.github.io/tp/UserGuide.html). TeachAssist requires Java 25.
