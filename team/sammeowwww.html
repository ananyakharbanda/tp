Samuel Lau

Project: TeachAssist

TeachAssist is a Java desktop application that helps teaching assistants manage student records, group labels, remarks, and attendance through a command-line interface and a JavaFX graphical interface.

Selected contributions

The following are selected contributions supported by commits and merged pull requests in the project history.

Features and data model

  • Implemented the add-student workflow, including field validation, specific error feedback, and duplicate Student ID checks (PR #63).
  • Implemented deletion by Student ID, including students hidden by a search filter (commit 39db8eda, PR #64).
  • Added optional student remarks to the model, commands, JSON storage, and student cards (PR #53).
  • Removed obsolete phone and address fields, then removed tags after group labels replaced them (PR #57, PR #91).
  • Enabled the edit command to add and remove group labels (PR #122).
  • Added attendance records and JSON persistence, then implemented the mark command (PR #140, PR #141).

Reliability and code quality

  • Saved student changes before updating the live model, so a failed save does not apply the proposed change (commit 44ca1cd7).
  • Protected student data after startup loading failures (commit 44a6fdc5).
  • Fixed misleading list and find results after loading failure, attendance rows with long names, and the visual distinction between Student IDs and group labels (PR #225).
  • Added outcome logging for the add and mark commands (PR #179).
  • Refactored commands, parsers, and model classes for clearer responsibilities and defensive checks, and expanded related tests (PR #212).
  • Improved add, delete, and edit test coverage using equivalence partitioning and boundary value analysis (PR #174).

Documentation

  • Updated the Developer Guide's target user profile, value proposition, and user stories (PR #42).
  • Updated the User Guide and Developer Guide for add and delete, including their execution sequence diagrams (commit f4c38f50, PR #92).
  • Documented add and delete error-message precedence and the edit-label execution sequence (PR #106, PR #154).
  • Updated the User Guide screenshot and clarified attendance and data-file recovery guidance (PR #123, PR #256).
