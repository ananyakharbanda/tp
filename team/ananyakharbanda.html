Ananya Kharbanda

Project: TeachAssist

TeachAssist is a Java desktop application that helps teaching assistants manage student records, group labels, remarks, and attendance through a command-line interface and a JavaFX graphical interface.

Contributions

My work covers student listing and remark editing, UI improvements, application reliability, testing, and project documentation. The contributions below link to merged pull requests, project commits, and issue reports. Related issues are grouped where they describe the same work.

Features

  • Implemented student listing, including restoring the complete list after searching, validating arguments, handling an empty list, and aligning command feedback with the feature specification (issue #65, issue #67, issue #95, issue #99, PR #68, PR #96, PR #100).
  • Added support for editing and clearing student remarks, preserving remarks when omitted, and validating command parameters (PR #66).
  • Integrated group-label filtering into the find command while preserving exact, case-insensitive label matching (PR #130).
  • Removed the redundant label command, with labels assigned through the add command (issue #120, PR #121).

UI and usability

  • Made long student names and email addresses wrap within student cards (issue #133, PR #134).
  • Adjusted the application window to fit scaled displays (issue #135, PR #136).
  • Fixed long group labels clipping student details in narrow windows (issue #214, PR #220).
  • Kept attendance badges visible beside long student names (issue #215, PR #222).
  • Made long attendance headings display the group and date (issue #216, PR #223).
  • Pointed the Help window to the TeachAssist User Guide and restored it when reopened after being minimized (issue #131, issue #240, PR #132, PR #250).
  • Fixed the attendance list overflowing below a wrapped heading (commit 6dabbd2e).

Startup, storage, and privacy

  • Fixed startup crashes caused by null JSON data and file-logging failures (issue #124, issue #126, PR #125, PR #127).
  • Kept application files beside the JAR and corrected packaged-path tests and coverage reporting (issue #128, PR #129).
  • Rejected malformed student-data JSON, duplicate keys, and invalid field types (issue #234, PR #244).
  • Added protection against concurrent application instances overwriting student data (issue #235, PR #245).
  • Removed student details and remarks from diagnostic logs (issue #237, PR #252).
  • Blocked attendance reports when student data failed to load (issue #238, PR #248).
  • Fixed JavaFX compatibility with native Apple Silicon Java (issue #236, PR #246).

Testing and bug reporting

  • Made JavaFX test initialization reliable and bounded so initialization failures or timeouts fail explicitly (issue #239, PR #251).
  • Recorded the team's alpha-testing task split and completion of my assigned testing areas: adding and deleting students, marking and unmarking attendance, viewing attendance, and clearing records (issue #190).
  • Reported reproducible alpha bugs involving concurrent data overwrites, clipped student details, hidden attendance badges, truncated attendance headings, and pasted tab separators (issue #213, issue #214, issue #215, issue #216, issue #217).
  • Added application lifecycle tests and improved packaged-path and logging-subprocess coverage (commit d496be75, commit 058313fd, commit 673827f6).

The tab-separator report in issue #217 was resolved by Tristan's documentation changes in PR #219; my contribution was identifying and reporting the problem. The concurrent-overwrite report in issue #213 was initially addressed by the same documentation PR; I later implemented write protection under issue #235 and PR #245.

  • Aligned guide expectations with undo behaviour and startup loading failures (issue #241, PR #249).
